## 🎯 Overview

This project presents an **AI-powered real-time fire and smoke detection system** using **YOLOv10** integrated with a **Flask web application**.

Traditional fire detection systems are slow and prone to false alarms. This system uses **computer vision and deep learning** to detect fire hazards instantly and provide visual confirmation.

---

## ⚡ Features

- 🔥 Real-time fire & smoke detection  
- 🎥 Supports image, video & live webcam  
- 🧠 YOLOv10 deep learning model  
- 🌐 Flask-based web interface  
- 📊 Performance charts & analytics  
- 🚨 Instant alert system  
- 🧩 Modular & scalable architecture

## ⚙️ Installation

git clone https://github.com/Nagesh-kamane/Real-Time-Fire-and-Smoke-Detection-Using-YOLOv10-and-Flask.git

cd fire-smoke-detection

python -m venv venv\
venv\Scripts\activate

pip install -r requirements.txt\
python app.py

🧠 How It Works\
User uploads image/video or starts webcam\
Frames are processed using OpenCV\
YOLOv10 detects fire/smoke\
Bounding boxes + labels are displayed\
Alert is triggered if detected

📊 Results\
⚡ Fast detection speed\
🎯 High accuracy\
🔻 Reduced false alarms\
🌙 Works in different lighting conditions

⚠️ Limitations
Depends on camera quality\
Performance affected by lighting\
No hardware sensors used
